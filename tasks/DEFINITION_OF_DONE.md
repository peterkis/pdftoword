# Definition of Done

Ticket 只有同时满足以下条件才完成：

- [ ] 实现范围与 Ticket 一致，没有擅自扩大边界。
- [ ] 有单元测试；涉及 Adapter 有 Mock/契约测试。
- [ ] 涉及样本文档有黄金测试或集成测试。
- [ ] 类型检查、lint、Schema 验证通过。
- [ ] 错误使用统一错误码，不吞异常。
- [ ] 结果包含来源、版本、哈希或候选证据。
- [ ] 普通日志不含正文、图像或秘密。
- [ ] 文档、配置和变更记录已更新。
- [ ] 提供可复现的验证命令和结果摘要。
- [ ] 没有将模型原始输出直接传给 DOCX Builder。
- [ ] 低可信路径有审校或图片降级。
- [ ] 不存在对试卷内容的静默纠正。
