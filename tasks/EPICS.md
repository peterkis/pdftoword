# Epic 清单

## P0 工程基础与契约

建立可测试、可替换、可追溯的工程骨架，冻结 Layout IR 1.1、作业状态机、Adapter 和模型网关契约。

**前置控制任务（V1.1 新增）**：
- T0014 / P0-BASELINE-001：模型部署基线与架构文档对齐
- T0015 / P0-GATE-001A：服务契约发现
- T0016 / P0-GATE-001B：JPG/PNG 与数学试卷回归
- T0017 / P0-GATE-001C：旋转、UVDoc、多栏、表格和公式专项能力矩阵

**任务总数**：17（原 13 + 新增 4）

## P1 纯电子 PDF MVP

在完全不依赖 OCR/VLM 的情况下，将正常电子 PDF 转换为基本可编辑 DOCX。

## P2 混合 PDF 与局部 OCR

完成页面/区域分流、PP 新版布局、局部 PP-OCRv6、隐藏层去重和配图保留。

## P3 扫描 PDF 专项模型

完成纯扫描页面的文字、表格、公式和图片分区处理，以及安全降级。

## P4 MonkeyOCRv2 与多模型融合

接入 MonkeyOCRv2 复杂版面主链路，加入 Ovis 内容复核和候选融合。

## P5 题目结构与高保真 DOCX

恢复题目层级、题图关系、表格/公式输出和稳定 Word 布局。

## P6 QA 与人工审校

建立问题检测、回渲染、区域重识别、人工修正和审计闭环。

## P7 性能、安全、部署与发布

完成性能优化、模型机安全、打包、SBOM、运行手册和发布资格验证。
