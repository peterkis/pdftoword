# R1-05 POC 冻结结论

本记录取代初次实施报告中有关“当前支持范围”的描述；历史产物、失败记录和审查纠正均保留。按用户最新指令，处理已发现的实验可信度问题后停止扩展能力，不再主动触发新一轮全面审查。

## 决定

可在最终针对性验证及既有 CI 正常后，作为**带已知限制的 POC**合并。默认生产路径仍使用 Legacy，不将 DocVortex 声明为完善的重建或渲染引擎。工程合并不等于视觉、Microsoft Word 或产品接受。

## 可继承的边界

| 类别 | 冻结结论 |
| --- | --- |
| 公共结构调用 | 可采用隔离运行时、公共 ModelJson→MiddleJson 调用、独立来源账本、保真门和失败报告。只有已映射、内容/几何保留且未人工锁定的候选可采用。 |
| 结构与渲染分离 | 可继承独立 StructureProcessor / Renderer 接缝、同源回放及实际实现指纹。记录实际执行者；Legacy 回退不得算作成功的 DocVortex 对照。 |
| 有限输出子集 | 可按能力检查选择普通文字、行内图片及已验证的有限 OMML 输出；必须通过内容、顺序、来源、可见性和容器检查。它不是生产默认选择。 |
| 拒绝及回退 | 可继承明确的不支持记录、原始 SDK 候选、源文件不变检查、公式回退次数/区域与逐页可编辑性证据。失败不能标作成功。 |
| 状态发布 | 可继承 JSON 原子发布及真实上传轮询竞态回归；已证明不会读到半份状态 JSON。不能把所有历史 CI 偶发失败都归因于此。 |

## 暂不支持

- 非零块/页旋转、复杂分栏和强制分页、非行内图片位置、分组布局、非空子块层级。
- 计划的 Heading 1 与公共 schema 不兼容的情况；块级源样式、复杂行内样式、超链接、列表及未实现的结构块。
- 表头及富文本单元格；SDK 表宽超出独立检查器保守上限的表格。原始表格可保留为候选，但不得记录为已接受的可编辑表格对照。
- 图片替代文本、非保图图片模式、冲突的内容/渲染策略、超出有限核验范围的公式。OMML-only 失败不能冒充允许的图片回退。
- 未绑定的正文/页眉页脚载荷、改变的输出容器、隐藏文字或图片、未支持的图片容器和分页控制。

这些能力不在 R1-05 继续补齐。样式/层级/列表边界交给 R2-01/R2-02，题图与布局交给后续 Flow Planner 及 R2 图文任务，表格/公式/富文本交给 R3-01/R3-02/R3-03。每项是否采用仍须真实输入输出证据。

## 主线承接

按计划依赖推进 R1-02 → R1-03 → R1-04 → R1-06 → R1-07 → R1-08。先让几何候选和仲裁真正进入当前问题页，再集成共享结构与布局；不为等待 DocVortex 达到全能力而阻塞主线。

后续继承的是**经过验证的适配边界、原始证据和失败案例**。用同一问题页保留 source / Legacy / 新候选对照，区分结构收益、渲染差异与回退；没有可视证据时不宣称排版改善。真实模型发送仍须遵守输入范围、目标、参数和预算的授权边界。
