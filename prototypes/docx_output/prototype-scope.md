# DEMO-001 范围与验收边界

用户于本轮明确授权独立输出验证原型：Replay → 最小 Layout IR → DOCX → Native PDF/本地审阅 → 可选 live。评测任务过去的“不实现 DOCX”约束不适用于本轮；T0015/T0016 的源码、协议、真值和历史实验仍只读。

## 已实现范围

- 使用原封存响应的固定 JPG 第 1 轮回放，schema-valid Layout IR 1.1、真实 python-docx 文档、图片和公式源区域裁剪。
- 有真实 OCR 行首与精确文本后缀证据才自动拆开合并题目。没有可靠子行几何时保留父 bbox 并标记近似。多个选项同段进入审阅，不按小数点盲切。
- PP 为**本 demo 的可复现自动正文基线**，不成为新永久权威。Monkey 的 normalized_1000 坐标单独保存并显示；Ovis 原文和相似段候选供显式审阅。没有读取 GT 或参考答案作为转换输入。
- 使用原始图域加小 padding 保留普通图与图内文字；已有题号图题形成 references，实际图行单独编排。无对应题干时创建 `target_not_in_input`，不挂到上一题。相邻图选项标签形成 2×2 无边框布局表格；它不是可编辑数据表格。
- native_pdf.py 是 **demo 内有限 PDFium 提取器**。仓库尚无可调用的 pdf-inspector 实现，不编造 API。保留字符、原生字体信息、字号和源几何；使用 PDFium 的页面变换处理 CropBox/旋转，按行恢复顺序。图像和相邻矢量组件整体保留。
- FastAPI 只绑定 127.0.0.1，原生 HTML/CSS/JS。一个作业 worker，无数据库、任务队列、账户、React/Node 构建或桌面壳。CLI/UI 共用 pipeline。
- 带原因的编辑、候选接受、拆分/合并/移动、裁剪、语义关联和 render_policy 更改；保存 overrides 并另存 reviewed，保留自动与人工差异。演示操作不是用户内容验收。

## 开发直连例外

本轮用户明确允许 demo backend 通过既有 FRP visitor 直连 PP 8080、Ovis 8000、Monkey 9000。例外仅限 `raster_bridge.py`，浏览器永远只访问本机 demo backend；生产 UI/Core 仍应连接尚未部署的 8100 网关。没有修改生产边界、模型职责、ADR-006 或部署基线。

PP 使用已冻结 `/layout-parsing` JSON Base64 契约；关闭方向、展平、印章、表格、图表和 Markdown 图片返回，开启公式区域识别。Ovis 8192、Monkey 2048。没有服务探测、调参、隐式重试、重新跑矩阵或访问响应内图片 URL。仅显式选择 raster 且给出授权与无鉴权确认时允许发送。失败/STARTED 均缓存，导出无推理。

## 有限能力与降级

第一版只承诺简单单栏、水平、正常编码 1–3 页电子 PDF。多栏、复杂表格、混合文字层、破损编码、拍照展平、旋转文字均需复核，不能把少量字符阈值当作可信电子文档判定。未知情况保留已有内容/原页参照，创建路由问题，不自动 OCR。加密 PDF 暂不接受密码，明确拒绝。

原生路径以字符字体框按行恢复，尚未实现完整段落重流、多级题组、多页续题、复杂表格恢复、隐藏层自动清理或一般 PDF Form XObject 组合几何保证。遇到不确定图域可用审阅页重新框选；本轮的简单合成样本不代表复杂 PDF 通过。

0.2.0 实现有限 LaTeX→OMML：分式、平方根、上下标和常用符号可编辑；不是通用转换器。已定位但不支持或关键符号冲突的公式仍以源图内嵌；无法定位则最小已知完整局部块降级，原候选仍在。仅简单候选显示表达式的定界符可以作为展示语法移除，不更改数学符号。原页参照不计作主要转换；没有可编辑正文则 `DEMO_OUTPUT_INSUFFICIENT`。

所有截图/图片/OCR 都是不可信数据；HTML 文本转义或 textContent，禁外部脚本、字体、图片和公式服务。Host/Origin 校验、会话 token、SameSite cookie、上传大小/页数/格式限制、已登记 job_id/asset_id 访问和符号链接检查是原型的本机隔离措施，不是完整生产安全评估。

默认输入 25MiB，图片与 PDF 渲染长边最多 4000px，最多选择 3 页。这些是资源限制，不是识别质量或性能结论。

## 状态解释

1. **程序能生成合法 DOCX**：Layout IR Schema 与 ZIP/OOXML/关系/图片/非空可编辑 run 检查提供证据。
2. **自动输出仍有问题**：正文/选项分块、候选冲突、图题关系和公式降级保留 issue；实际 LibreOffice 页面单独检查，不以 HTML 代替 DOCX 渲染。
3. **修正多少次才可用**：manual_override_count 只计有理由的操作。示例一次拆分说明流程有效，不代表一项修正足以使整张试卷可用。需用户继续在 Word 内确认。

未执行 T0017、完整 P1/P2/P3、正式 Adapter、网关、桌面应用、部署或新的实验矩阵。不更改或批量完成生产 Ticket；`PRODUCTION_READINESS = NOT_CLAIMED`。


## 0.3.0 经用户授权的 Ovis 独立回放

Ovis 成为默认 Replay 的正文、公式及普通图域来源；旧 PP 基线仅通过显式选项保留。Ovis-only 导入器不读取 PP/Monkey 响应，不使用 GT、人工 overrides 或旧 DOCX 内容。图片标签的 normalized_1000 约定来自官方模型说明，转换记录在 provenance 中；正文行和公式 bbox 未提供，不能借用 PP 坐标冒充 Ovis 定位。

普通试卷选项按数学表达式之外的空白边界标签切段；页脚仅合并明确相邻的“第”与页码片段，记录来源。未实现新的通用表格/复杂 Markdown 解析或 live 默认调用策略迁移。原有生产职责和 Gate 结论仍须与这份原型输出验证分开。

## 0.4.0 经用户授权的混合验证

默认 Replay 为 Ovis 内容＋PP 图片/布局几何。PP 只投影标签、区域框、OCR 行框及公式框坐标；识别文字、公式值既不用于文本匹配，也不成为输出候选。Ovis 内容保持不变。

同类顺序、缩进和图域唯一重叠是本次有限关联依据，不是通用几何仲裁。共享框只定位整行，分列仅是展示计划；不按字符数量伪造来源 bbox。列宽和相邻保持规则帮助恢复原图结构，不宣称字体、间距、DPI 或像素完全一致。历史结果与独立 Ovis 模式保留。


## 0.5.0 规则固化与 demo 上传一致性

按用户要求固化通用重建规则，默认上传改为 Ovis 内容＋PP 几何，与 Replay 共用实现。每页 Ovis、PP 各至多一次，须用户显式发送授权；本次实现仅用离线模拟调用验证，没有新 live 推理。布局失败保留 Ovis 并要求审校，Ovis 失败不切换文字提供者。多页逐页判定，不将一页通过等同整份通过。

适用范围仍为有限单栏试卷，规则没有保证 OCR 准确率。生产模型职责、ADR-006、8100 网关边界和 Gate 阶段保持原规范。
