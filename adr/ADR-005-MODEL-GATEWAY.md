# ADR-005：统一模型网关

状态：Accepted — Amended

## 决策

**生产目标**：主应用只连接统一网关 `8100`。

**Provider 配置**：网关通过配置连接当前 Provider：
- MonkeyOCRv2: `9000`
- OvisOCR2: `8000`
- PP-StructureV3: `8080`

**历史端口**：`8102` / `8104` / `8106` 为早期设计端口，不是固定内部服务契约。

## 网关职责

网关负责鉴权、队列、显存和输出规范化。

## 修订记录

- **历史原始决策**：主应用只连接 8100；历史端口 8102/8104/8106 为内部服务
- **修订原因**：当前部署基线为 9000/8000/8080，统一网关 8100 尚未部署
- **修订日期**：2026-08-28
