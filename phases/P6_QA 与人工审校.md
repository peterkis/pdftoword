# P6 — QA 与人工审校

## 阶段目标

建立问题检测、回渲染、区域重识别、人工修正和审计闭环。

## 具体任务

### T0601 Issue 生成器

- 优先级：`P0`
- 依赖：T0009, T0409, T0514
- 目标：从路由、候选、结构和 Builder 生成统一问题。
- 交付：
  - IssueRules
  - severity mapping
- 验收：
  - 每个问题有建议动作
  - 可定位页/块

### T0602 内容与结构 QA

- 优先级：`P0`
- 依赖：T0601
- 目标：遗漏、重复、顺序、覆盖、冲突和题图检查。
- 交付：
  - QaEngine core
- 验收：
  - 黄金故障样本可命中
  - 误报可配置

### T0603 DOCX 包和重新打开检查

- 优先级：`P0`
- 依赖：T0514
- 目标：验证 ZIP、XML、关系、图片和重新加载。
- 交付：
  - DocxIntegrityChecker
- 验收：
  - 损坏样本可发现
  - 通过样本100%打开

### T0604 DOCX 回渲染 Adapter

- 优先级：`P0`
- 依赖：T0603
- 目标：使用可配置后端生成回渲染页面。
- 交付：
  - RenderBackend protocol
  - implementation
- 验收：
  - 失败不破坏DOCX
  - 后端可替换

### T0605 结构化视觉比较

- 优先级：`P0`
- 依赖：T0604
- 目标：发现丢图、重叠、空白、方向、题图分离和表格崩坏。
- 交付：
  - VisualQa
  - metrics
- 验收：
  - 不以像素完全一致为目标
  - 问题可定位

### T0606 审校 API

- 优先级：`P0`
- 依赖：T0011, T0601
- 目标：读取页面/块/候选，修改内容、类型、关系和策略。
- 交付：
  - Review endpoints
  - audit records
- 验收：
  - 权限/路径安全
  - 修改可重建

### T0607 审校 UI

- 优先级：`P0`
- 依赖：T0606
- 目标：页面预览、候选对比、题图分配、问题列表。
- 交付：
  - React review screens
- 验收：
  - 不在UI实现业务规则
  - 修改有确认

### T0608 人工修正与锁定

- 优先级：`P0`
- 依赖：T0606, T0008
- 目标：创建 manual_correction 候选并防自动覆盖。
- 交付：
  - ManualCorrectionService
- 验收：
  - 审计完整
  - 可撤销

### T0609 区域重识别

- 优先级：`P0`
- 依赖：T0301, T0409, T0608
- 目标：选择模型、DPI和策略追加候选并重新融合。
- 交付：
  - Reprocess endpoint
  - UI action
- 验收：
  - 旧候选保留
  - 有次数/资源限制

### T0610 质量和转换报告

- 优先级：`P0`
- 依赖：T0602, T0603, T0605
- 目标：导出页类型、模型、降级、问题、字体和来源摘要。
- 交付：
  - JobReport
  - download artifact
- 验收：
  - 不泄露全文
  - 数据与作业一致

## 阶段退出门槛

- [ ] Issue 体系完整
- [ ] DOCX 完整性和回渲染可运行
- [ ] 审校修改有审计
- [ ] 区域可重识别
- [ ] 输出质量报告可下载
