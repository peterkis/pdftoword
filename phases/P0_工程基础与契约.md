# P0 — 工程基础与契约

## 阶段目标

建立可测试、可替换、可追溯的工程骨架，冻结 Layout IR 1.1、作业状态机、Adapter 和模型网关契约。

**重要变更**：P0 新增四个前置控制任务（T0014-T0017），用于模型部署基线对齐和服务契约验证。详见 `docs/23_MODEL_DEPLOYMENT_BASELINE_V1_1.md`。

## 具体任务

- 优先级：`P0`
- 依赖：T0001
- 目标：将仓库中的产品文档、架构文档、ADR、模型角色矩阵、路由配置、阶段计划和任务目录，与当前真实部署基线对齐。
- 交付：

  - 更新后的任务目录（T0014-T0017）
- 验收：
  - [ ] 文档与当前部署事实一致

  - [ ] 目标架构与当前部署明确区分
