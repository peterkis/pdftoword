# P1 — 纯电子 PDF MVP

## 阶段目标

在完全不依赖 OCR/VLM 的情况下，将正常电子 PDF 转换为基本可编辑 DOCX。

## 具体任务

### T0101 PDF 文件预检

- 优先级：`P0`
- 依赖：T0005, T0009
- 目标：读取文件信息、加密、页数、尺寸、旋转、损坏和哈希。
- 交付：
  - PreflightService
  - 报告模型
- 验收：
  - 源文件不修改
  - 损坏/加密有明确错误

### T0102 PDFium 页面几何与渲染

- 优先级：`P0`
- 依赖：T0101
- 目标：实现 MediaBox/CropBox/旋转和像素↔PDF point 转换。
- 交付：
  - PageGeometry
  - Renderer
- 验收：
  - 旋转四方向测试
  - 区域裁剪误差在阈值内

### T0103 pdf-inspector Adapter

- 优先级：`P0`
- 依赖：T0101, T0006
- 目标：封装页面分类、文字、字体和编码信息。
- 交付：
  - PdfInspectorAdapter
  - 版本探测
- 验收：
  - 原始输出不泄露到核心
  - 异常映射

### T0104 原生文字质量评分

- 优先级：`P0`
- 依赖：T0102, T0103
- 目标：计算 Unicode、乱码、覆盖、顺序、重复和隐藏层指标。
- 交付：
  - NativeTextQualityScorer
  - 阈值配置
- 验收：
  - 已知乱码样本可识别
  - 正常文本不过度拒绝

### T0105 原生文字转 Layout IR

- 优先级：`P0`
- 依赖：T0007, T0103, T0104
- 目标：生成文字块、run、样式、来源和阅读顺序候选。
- 交付：
  - NativeTextExtractor
  - IR writer
- 验收：
  - 字体/字号/上下标保留
  - 所有 run 有来源

### T0106 图片和矢量对象提取

- 优先级：`P0`
- 依赖：T0102, T0005
- 目标：提取原图；复杂矢量组合区域渲染。
- 交付：
  - ImageExtractor
  - VectorRegionRenderer
  - Asset records
- 验收：
  - 透明/裁剪/旋转图片正确
  - 资产去重

### T0107 简单阅读顺序与段落聚合

- 优先级：`P0`
- 依赖：T0105
- 目标：基于坐标、基线、间距和样式合并行/段落。
- 交付：
  - ReadingOrderSimple
  - ParagraphGrouper
- 验收：
  - 单栏/双栏基础样本正确
  - 页眉页脚可分离

### T0108 样式归一化与字体映射

- 优先级：`P0`
- 依赖：T0105
- 目标：建立 Word 样式候选和字体回退。
- 交付：
  - StyleNormalizer
  - FontMap
- 验收：
  - 中英文字体分开处理
  - 输出字体替换报告

### T0109 基础 DOCX Planner/Builder

- 优先级：`P0`
- 依赖：T0106, T0107, T0108
- 目标：输出标题、段落、列表和行内图片。
- 交付：
  - DocxPlan
  - BasicBuilder
- 验收：
  - DOCX ZIP 有效
  - 可重新打开
  - 无绝对定位滥用

### T0110 电子 PDF 端到端作业

- 优先级：`P0`
- 依赖：T0109, T0011
- 目标：串联预检、提取、IR、DOCX、报告。
- 交付：
  - Pipeline native
  - CLI command
- 验收：
  - 无模型机可完成
  - 正常文字模型调用=0

### T0111 电子 PDF 黄金回归

- 优先级：`P0`
- 依赖：T0110, T0012
- 目标：建设并验证普通报告、标准、中英混排、图片文档。
- 交付：
  - Golden set P1
  - 回归报告
- 验收：
  - 内容/图片/顺序通过
  - DOCX 可打开率100%

## 阶段退出门槛

- [ ] 黄金电子 PDF 文本和图片完整
- [ ] 正常原生文字 OCR 调用次数为 0
- [ ] DOCX 可打开
- [ ] 基本标题、段落、列表和图片顺序正确
- [ ] 无模型机时可运行
