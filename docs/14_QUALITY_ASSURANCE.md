# 14. 质量保障

## 1. 验证层次

1. 输入与资产完整性；
2. Layout IR Schema；
3. 内容与来源；
4. 阅读顺序和结构；
5. 题图关系；
6. 表格和公式；
7. DOCX ZIP/OOXML 完整性；
8. DOCX 重新打开；
9. 可选回渲染；
10. 人工审校。

## 2. 关键指标

- 中文 CER；
- 英文 WER；
- 数字、单位、符号准确率；
- 文字块覆盖率；
- 阅读顺序准确率；
- 块 IoU；
- 表格 TEDS/结构一致性；
- 公式渲染相似度；
- 图片-题目归属准确率；
- 重复文字率；
- 图片丢失率；
- DOCX 可打开率；
- 页级异常率；
- 模型调用和降级比例。

## 3. 回渲染定位

不要求逐像素相同，回渲染主要发现：

- 图片丢失；
- 公式崩坏；
- 表格严重错位；
- 文字重叠；
- 大面积空白；
- 页面方向错误；
- 题图分离；
- 字体替换造成异常。

## 4. 自动降级

- 公式回渲染失败 → 图片；
- 表格结构不可信 → 图片；
- 题图归属低分 → Issue；
- 复杂局部重建异常 → 局部图片；
- 页面内容覆盖不足 → Ovis 或人工复核。

## 5. 黄金测试集

测试集必须覆盖：电子、混合、扫描、隐藏层、乱码、数学、英语、化学、表格、公式、拍照、倾斜、多栏和复杂题图。详见 `tasks/TEST_DATA_PLAN.md`。
