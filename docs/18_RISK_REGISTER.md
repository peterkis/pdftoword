# 18. 风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| Monkey 输出无可靠概率 | 错把经验分当模型置信度 | engine/system confidence 分离 |
| 复杂页全依赖 VLM | 延迟和幻觉 | 原生优先、快速初筛、专项复识别 |
| 16GB 显存竞争 | OOM | 网关队列、profile、单并发、按需加载 |
| 电子 PDF 被 OCR | 引入错字 | 路由硬规则和调用审计 |
| 隐藏层重复 | Word 重复文字 | 几何+内容去重 |
| 表格强制重建 | 错位 | 结构阈值和图片降级 |
| 公式误识别 | 语义错误 | 专项模型+回渲染+图片回退 |
| 题图错配 | 试卷不可用 | 显式关系、阈值、人工审校 |
| trust_remote_code | 供应链风险 | revision 固定、隔离、审查、断网 |
| 模型升级漂移 | 回归 | 影子评测和模型注册表 |
| Word 字体差异 | 版式变化 | 字体映射和替换报告 |
| 绝对定位滥用 | Word 漂移 | 流式布局和无边框表格 |
| 敏感文档日志泄露 | 合规风险 | 不记录正文、自动清理 |
| 网关不可用 | OCR 阻断 | 原生模式继续、作业可重试 |
