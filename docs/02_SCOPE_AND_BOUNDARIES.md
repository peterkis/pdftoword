# 02. 范围与产品边界

## 1. 纳入范围

- PDF 导入、预检和分类；
- 电子 PDF 原生文字/图片/样式提取；
- 混合 PDF 局部 OCR；
- 扫描 PDF 分区域识别；
- 中文、英文和中英文混排；
- 标题、正文、列表、题目、选项、表格、公式、图片和图题；
- 题目与图片显式关系；
- DOCX 流式重建；
- 低可信区域图片降级；
- 本地/内网模型网关；
- 质量检测和人工审校；
- 可选 Layout IR、报告和问题清单导出。

## 2. 第一版重点文档

- 正式制度、报告、标准；
- 数学、英语、化学试卷；
- 原生文字为主、局部图片/扫描内容；
- 中等质量扫描文档；
- 常规表格、公式和插图。

## 3. 不在第一版承诺范围

- 手写答案高精度识别；
- 极端弯曲、严重遮挡或超低清晰度拍照；
- 复杂化学结构可编辑化；
- CAD、工程制图、乐谱完整结构恢复；
- 复杂图表数据重建；
- 模板级像素还原；
- 云端账户和协同编辑。

## 4. 可编辑性边界

### 默认可编辑

- 有效原生文字；
- OCR 正文；
- 标题、列表和题目；
- 高可信普通表格；
- 高可信公式。

### 默认保留图片

- 几何图；
- 实验装置图；
- 化学结构图；
- 流程图和复杂图文组合；
- 低可信表格或公式；
- 无法安全拆分的局部区域。

### OCR 仅作元数据

图片内部的字母、图例、化学式和标签可 OCR 用于检索、关联和校验，但 Word 中默认仍保留原图，避免位置破坏。

## 5. 分页边界

允许 Word 自然重分页。只保证必要关系：

- 标题不孤立在页尾；
- 题号与题干不分离；
- 图片与直接引用图片的题干尽量不分离；
- 图片与图题不分离；
- 短题尽量整体；
- 长题允许跨页。

## 6. 模型边界

- MonkeyOCRv2 只负责复杂页结构主证据。
- PP-OCRv6 负责栅格文字主结果。
- PP-StructureV3 负责表格主结果。
- PP-FormulaNet 负责公式主结果。
- OvisOCR2 负责复核，不默认全页调用。
- 所有模型都不能直接生成最终 DOCX。

## 7. 网络边界

- PDF 原文件不上传公网；
- 模型机必须位于受控网络；
- 主应用只访问模型网关；
- 模型网关不可达时，支持纯电子模式继续运行；
- 需要模型的页面进入可重试失败或待处理状态，不静默跳过。
