# 12. DOCX Builder

## 1. 目标

生成稳定、可编辑、图文关系正确的流式 Word，而不是用文本框逐页仿制 PDF。

## 2. 分层

### Planner

读取 Layout IR，决定：

- 段落/标题；
- Word 原生表格；
- OMML；
- 行内图片；
- 无边框布局表格；
- 浮动对象；
- 局部图片降级；
- 分页控制。

### Builder

将 Plan 转换为 WordprocessingML、DrawingML 和 OMML。

## 3. 输出优先级

```text
原生段落 / 表格 / OMML
  > 行内图片
  > 无边框布局表格
  > 浮动对象
  > 局部图片
  > 整页图片
```

## 4. 字体

- 优先映射原字体；
- 缺失时按中文/英文字体回退；
- 保存字体替换报告；
- 字体替换不得改变字符内容。

## 5. 段落

恢复对齐、缩进、行距、段前段后、粗斜体、上下标和制表位。不要机械保留 PDF 每行换行。

## 6. 图片

- 尽量提取原始图片；
- 矢量组合使用高分辨率区域渲染；
- 设置最大宽度；
- 题图与题干使用稳定容器；
- 图片内部 OCR 不替换原图。

## 7. 表格

- 依据单元格坐标和跨度创建 Word 表格；
- 恢复列宽、行高、边框和对齐；
- 低可信直接图片降级；
- 不将 Markdown 表格作为结构来源。

## 8. 公式

- LaTeX → MathML → OMML；
- 验证结构和回渲染；
- 失败使用原公式图片；
- 保留原 LaTeX 和资产引用。

## 9. 分页

使用：

- `keep_with_next`；
- `keep_together`；
- widow control；
- 表格行 `cantSplit`；
- 必要的 `page_break_before`。

短题尽量整体，长题允许自然跨页。

## 10. 禁止

- Builder 直接调用模型；
- 大量绝对定位文本框；
- 为追求页数一致强制缩放字体；
- 低可信对象强制可编辑；
- 丢弃原始裁剪图和来源映射。
