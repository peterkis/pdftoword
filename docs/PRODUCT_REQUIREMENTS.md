# PDF2Word 项目最终需求

需求基线：2026-09-21；状态：用户明确确认范围与目标。此状态不表示软件质量已验收。

## 最终目标

以试卷、合同、手册和一般文档为主要识别对象，将真实PDF/图片转换为内容准确、主要内容可编辑的Word，力求原布局与排版还原。

本目标适用于整个项目及后续阶段，不只是一次比较集的筛选规则。与历史需求、验收说明中的范围或排版表述冲突时，以本需求和用户后续明确变更为准。历史报告、原始产物和失败记录保留。

## 目标文档

- 试卷、练习题和试卷相关材料：题号、题干、选项、公式、表格、题图及跨页关联。
- 合同、协议：条款编号、正文、表格、附件引用、页眉页码及必要图像。
- 手册：操作、产品、技术、教学说明中的标题层级、列表、插图、图注、表格、公式及连续结构。
- 一般文档：制度、标准、报告、通知、业务说明等以正文和结构化信息为主的材料。

电子、扫描和页内混合是输入载体维度，不改变文档类别。正常原生文字优先保留，不能为统一流程整页OCR替代。

## 不作为项目识别目标

杂志、网络期刊及其栏目页、杂志封面等出版物版式不作为目标，不进入核心验收分母，不作为开发六栏杂志、艺术字、封面设计等专项能力的理由。“一般文档”不能用来重新把已排除的杂志/网络期刊纳入。

不因排除杂志而排除试卷或手册中真实存在的双栏、多栏、跨栏标题、图文混排、封面或跨页关系。按业务类别判断范围，不能按是否复杂、是否多栏或本次效果好坏筛样。

## 共同质量要求

1. 内容完整且不静默改写。有效文字、数字、题号、条款编号、公式符号等须有来源；遗漏、多出、错序和不确定项明确报告。
2. 主要正文可编辑；普通表格保留单元格关系；支持的公式以可编辑结构呈现。图片降级须有原因和范围，整页保图不能算可编辑成功。
3. 力求还原原页纸张尺寸及方向、页边距、分页、栏宽、跨栏区域、标题层级、字号、缩进、列表、表格尺寸和图文相对位置。
4. 题干—选项—题图、条款—附件、图—图注、跨页续表等关系稳定，不出现遮挡、异常裁切、丢图或误合表。
5. Word允许客观的字体/排版差异，但必须报告其影响；“自然重分页”不是放弃原布局目标的默认豁免。无需承诺逐像素一致，也不能用大量绝对定位文本框或纯图像偷换可编辑目标。
6. 普通图像使用源资产，不重画。保存、预览、样式调整和离线再导出不触发模型。

尚未定义的数值容差与准确率阈值须在相应验收profile中明确，不从单次样本得分倒推“通过线”。

## 评测与范围变更

核心指标按业务类别和载体分别展示。类别没有真实样本时标NOT_COVERED；采购说明页不自动证明合同条款能力，教学书页不自动证明所有技术手册能力。

范围变化后用独立scope清单从封存结果生成新报告；不重写历史分母、原标注、响应或DOCX，不把OUT_OF_SCOPE改成识别成功。排除依据是本需求，不是候选表现。

范围外材料可以保留为历史诊断证据，但不得决定当前主路线或触发专项实现。正式路线/质量批准、部署安装、模型请求和Git操作仍各自遵循已有授权，范围批准不自动批准这些动作。

本批具体裁决：用户确认supermix物理第3–6页全部排除。该裁决不代表所有学校业务文档都被全局排除。
