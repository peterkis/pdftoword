# 15. 安全、隐私与许可证

## 1. 数据分级

输入 PDF、页面图片、OCR 结果、模型原始输出、Layout IR 和 DOCX 均按敏感数据处理。

## 2. 日志

允许记录：

- 作业 ID；
- 文件哈希；
- 页码和区域 ID；
- 模型和版本；
- 耗时、重试、错误码；
- 候选数量和问题数量。

禁止记录：

- 完整正文；
- 页面图片；
- API Key；
- 用户文件路径中的敏感内容；
- 模型原始长文本。

## 3. 模型机

- 限制来源 IP；
- API Key；
- TLS 可用时启用；
- 模型容器禁止公网；
- 只读模型目录；
- 临时上传隔离和自动删除；
- 上传尺寸、像素和超时限制；
- 防止路径穿越和压缩炸弹。

## 4. trust_remote_code

MonkeyOCRv2 模型加载若需远程代码：

- 固定模型 revision；
- 保存代码快照和哈希；
- 代码审查；
- 隔离容器；
- 非 root；
- 禁止互联网；
- 不挂载宿主敏感目录。

## 5. 许可证

构建时生成：

- Python/Node/Rust SBOM；
- 模型名称、版本、revision 和许可证；
- 容器镜像 digest；
- 第三方声明文件。

不得引入未评估的强传染许可证作为不可替换核心。
