# 16. 非功能需求

## 1. 稳定性

- 单页或单区域失败不破坏整个作业；
- 每阶段可重复执行；
- 模型请求幂等；
- DOCX 可从已保存 IR 重建；
- 支持取消和安全清理。

## 2. 性能

- 按页和区域渲染；
- 不一次性加载整本 PDF；
- 图片资产去重；
- 原生页避免模型调用；
- Monkey/Ovis 单并发默认；
- 支持缓存同一输入哈希结果。

## 3. 可维护性

- 业务层依赖协议，不依赖具体模型；
- Schema 版本化；
- 路由阈值配置化；
- 模型升级通过影子评测；
- 错误码稳定。

## 4. 可观测性

按阶段记录：

- 页面数量；
- 页面类型；
- 模型调用次数；
- 队列时间和推理时间；
- 缓存命中；
- 降级；
- Issue；
- 输出大小和耗时。

## 5. 可用性

- UI 展示清晰进度；
- 错误可操作；
- 低可信区域可定位；
- 用户可以重识别区域；
- 导出报告解释哪些内容被降级。
