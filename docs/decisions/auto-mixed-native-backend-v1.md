# 自动混合入口与原生后端 v1

2026-09-17；依据用户明确批准的 S2-01～S2-06 实施计划。

pdf-inspector **1.20.0** 负责 PDF 分类、原生文字和字体提取；PDFium 负责页面渲染、图片/矢量对象、可见页框与几何转换。文字来源记录为 native_pdf，具体后端在候选和 provenance 中记录。上游分类只作证据，不能直接触发 OCR。内置 OCR 接口不进入应用调用链。

上游 run 的基线和范围不是逐字符精确框。Adapter 还原文字重定向，再应用可见页框和页面旋转；Form 父矩阵沿祖先链组合。原始框、四角、转换后框与未知裁剪信息保留。缺失/估算信息不冒充概率或精确可见性。

本阶段在既有开发入口扩展 mixed-ovis-pp-v1：原生文字优先；不确定区域经授权 PP 判断，Ovis 负责待识别内容，PP 只提供标签和几何。请求串行、无自动重试；服务端缓存复用须匹配源哈希、页选、profile、目标配置和区域输入。生产 Core/UI 统一网关边界不变，尚未实现网关部署或桌面分发。

路由准备不发送请求；批准绑定源文件、裁剪、准备后的IR、目标配置、页选、参数、到期时间和预算。执行生成新作业，原 auto 和 reviewed 不覆盖。取消停止后续发送，已有结果保留。重复执行同一计划被拒绝；显式新计划可以引用匹配的既有成功响应，记录来源与复用哈希。

单个 HTML 表格与唯一 PP 表格区域对应时，仅保留该表格源图并登记原始候选；正文继续可编辑。多表格或含糊对应不按顺序猜配。本项不宣称可编辑普通表格已完成。

T0103 已有真实 Adapter 接入依据，但其完整旧阶段验收不自动关闭。原生、隐藏层、区域路由、真实推理和 Pages 检查分别报告。1～3页、25MiB限制继续成立。当前Pages检查不代表Microsoft Word兼容性通过。
