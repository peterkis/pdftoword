# U1 路线决策：停止直接接入，结论 INCONCLUSIVE

状态：已形成裁决材料，用户接受及路线批准均PENDING。没有默认切换。

## 决策

现有官网pipeline、官网VLM与项目当前链路均未满足批准的保版式/可编辑/完整性目标。当前不选择DIRECT、COMPOSE、PATCH_RENDERER或RETAIN_SPECIALIST作为新的生产主路线，保留现有入口和历史作业。

官网VLM（比较实验C）不等于组合试验C。U1-03的probe_c在本轮收尾中设false：两个决定性案例都未形成“内容与结构已可用，仅剩布局问题”的证据。G1的误合表发生在上游结果；G5仍有缺失/丢弃内容及未核验关系。跳过组合开发不是宣称COMPOSE永久无效，也不是因为已有适配器缺能力就重写上游。

## 实物依据

- 固定29页矩阵有18份真实DOCX及实际Word回渲染；不新增模型调用。
- G1的Word人工拆表诊断约88.316秒，2张表恢复为3张，3页减为2页；仍未恢复原页边界和公式内容。Word保存改变了数学run/字符序列，原件不受影响。
- G5的Word人工方向/六栏诊断约56.434秒，仍5页且出现图片裁切；简单分栏不能恢复原布局。
- 两个时间是实际操作到保存的墙钟，不是完成修复时间，也不是人类平均工时。试验提前停止，完整修复时间未知；不伪填10分钟完成或假称耗尽上限。

42项v2.1任务和97旧Ticket的责任映射见同目录task-disposition.json；采用映射不修改历史接受状态。R1/R2成果继续继承，S1与其他无关模型研究不重开。

## 维护成本与下一条件

本轮停止新增比较调用、通用桥接平台和多生产分支；现有系统保留作为回退，不作质量胜出声明。没有源码删除/停用授权。
