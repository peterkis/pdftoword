# U1 路线裁决：核心文档范围修订版

决定：`U1-CLOSURE-20260921-SCOPE-V2`；路线：INCONCLUSIVE；批准：PENDING。替代同目录scope-v1决定作为当前结论，旧决定保留。

## 最终需求

用户已明确整个项目以试卷、合同、手册、一般文档为主要对象，力求原布局与排版还原，排除杂志、网络期刊。正式需求见[PRODUCT_REQUIREMENTS](../PRODUCT_REQUIREMENTS.md)。范围批准不是产品质量或路线批准。

本批supermix物理3–6页按用户确认排除。核心证据为G1–G4：25源页、12份自动DOCX、140页实际Word输出。历史29页/18份矩阵不改写；G5六栏修复、G6杂志封面丢图等不再作为当前否决理由。

## 当前决定

不进入U2，不替换默认解析或Renderer。四条生产路线的处置：

- DIRECT：实测官网配置在核心文档上仍不满足。试卷12页被重排为34/33页，表格公式字符串化，教学表列宽与跨页结果有严重缺陷。
- COMPOSE：没有同内容组合输出证明收益；本轮probe_c=false。G1上游误合表，G2/G3/G4的公式/表格内容与结构尚未验证可用，不能把主要缺口预设为排版一层。此项跳过不代表组合路线永久无效。
- PATCH_RENDERER：不选为当前主路径。上游结构错误不能归为Renderer缺陷；尚未证明少量补丁足以覆盖必需能力。
- RETAIN_SPECIALIST：保留原生提取、源资产、来源映射和现有入口作为回退；不宣称当前整套多模型链路胜出。

## 范围内实物与前三缺口

G1人工拆表约88.316秒，表数2→3、Word页数3→2，但没有恢复正确源页边界及公式内容。时间为代理操作到保存的墙钟，不是完整修复工时；完整修复时间未知。原件保留，副本的Word数学保存变化单列。

前三缺口仍为：内容/结构完整性；原布局及题图/续表关系；公式/表格真实可编辑性。决定由范围内缺陷支撑，不再使用杂志/宣传页表现。

五个gap均必要；未来首批候选tables/formulas/layout，relations/continuation延期保留，目前均不激活。42项v2.1任务和97旧Ticket只采用责任映射，不改历史接受、不删除旧源码。所有映射的实际激活须受新需求过滤，不能因“多栏”关键词恢复杂志目标。

本批覆盖试卷/练习、教学材料和采购说明，不能替代专门合同条款或技术/操作手册验收。原多栏诊断槽只含杂志，排除后记NOT_COVERED；试卷/手册中多栏仍是需求。

原计划本地MinerU4.0.4/受信V1链路与离线公共render_docx重导出仍NOT_RUN，官网v4后端3.4.4不能替代部署证据。重新开启路线选择时，先明确目标部署和版本；最多两个有界目标case，优先补合同/手册及现有试卷/表格，另定实际模型预算。不重跑29页、不继续杂志专项。
