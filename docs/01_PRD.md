# 01. PDF2Word Local 产品需求文档 V1.1

文档版本：`1.1.0`  
日期：`2026-08-20`  
产品形态：本地桌面应用；Python Core 可独立 CLI/本地服务运行；复杂模型由内网 GPU 模型机提供

## 1. 产品概述

PDF2Word Local 通过原生 PDF 解析、区域路由、模型识别、证据融合、结构重建和 DOCX 生成，将纯电子、混合和纯图像 PDF 转换为主要内容可编辑、结构关系正确、题图关系稳定、视觉布局高度相似的 Word 文档。

当前最终范围以[项目最终需求](PRODUCT_REQUIREMENTS.md)为准（用户于2026-09-21确认）：
主要对象为试卷、合同、手册和一般文档，排除杂志与网络期刊。
力求还原原布局与排版，页数、分页、分栏和图文位置均纳入评价；不承诺逐像素一致，
也不能以自然重分页为由免除布局验收。核心目标是：

> 内容准确、结构稳定、主要内容可编辑，力求原布局与排版还原；低可信时不破坏原文。

## 2. 目标

### P0

1. 支持纯电子、混合、扫描、隐藏文字层和编码损坏 PDF。
2. 有效原生文字不经过 OCR。
3. 页面级和区域级路由。
4. 中文、英文及中英文混排。
5. 标题、正文、列表、题目、选项、图片、表格、公式基础恢复。
6. 普通配图整体保留；局部扫描文字可编辑。
7. 生成有效 DOCX，并保留来源映射。
8. 模型失败可降级，不破坏已完成结果。
9. 默认本地/内网处理，不访问公网模型。

### P1

1. 题目块和图片归属。
2. MonkeyOCRv2 复杂页面几何与阅读顺序。
3. 多模型候选和融合。
4. 表格和公式按置信度原生重建或图片降级。
5. 隐藏 OCR 层检测与去重。
6. 人工审校和区域重识别。
7. 快速、平衡、高精度三档模式。
8. 回渲染 QA 和异常检测。

### P2

1. Windows/Linux 客户端；
2. 批量任务和断点恢复；
3. 模型插件和版本管理；
4. 模板/文档类型优化；
5. Markdown、HTML、Layout JSON 可选导出；
6. 与知识库编译器共享 Layout IR。

## 3. 非目标

- 与 PDF 页数和分页完全一致；
- 逐字符绝对坐标复刻；
- 所有图形完全可编辑；
- 复杂化学结构自动转为化学绘图对象；
- 图表数据反向恢复；
- 自动改写、翻译、润色或纠错；
- 绕过 DRM 或未经授权解密；
- 默认调用公网模型服务。

## 4. 用户故事

### US-01 纯电子 PDF

导入可正常复制文字的 PDF，系统直接提取原生文字、图片和样式，生成可编辑 Word。

验收：正常原生文字不调用 OCR；阅读顺序正确；图片完整；DOCX 可打开。

### US-02 混合 PDF 局部 OCR

大部分文字可提取，局部区域为扫描文字或图片表格。系统只识别局部区域，并与原生内容融合。

验收：无重复文字；普通配图不被拆散；局部扫描文字可编辑；来源可追溯。

### US-03 试卷题图关系

数学、英语或化学试卷的图片必须跟随对应题目。

验收：形成 QuestionBlock；图片存在 `anchored_to`；低置信度产生审校项；Word 使用稳定容器。

### US-04 纯扫描 PDF

系统对整页执行结构分析，再按文字、表格、公式和图片区域调用专项模型。

验收：正文可编辑；表格/公式可转换或安全降级；无隐藏层重复。

### US-05 复杂页面

复杂多栏、拍照、倾斜、题图密集页面由 MonkeyOCRv2 提供块级几何和阅读顺序，专项模型提供内容。

验收：Monkey 结果进入候选和证据层，不直接绕过 Layout IR；文字、表格、公式仍按职责融合。

### US-06 模型机不可用

GPU 模型网关不可达时，纯电子 PDF 仍能完成转换；需要 OCR 的作业清晰提示并可重试。

### US-07 本地隐私

文档不上传公网；普通日志不包含完整正文或页面图片；中间资产可清理。

## 5. 功能需求

### FR-001 文件预检

检查文件、MIME、PDF 版本、加密、页数、页面尺寸、旋转、损坏、超大页面、SHA-256。源文件只读，中间文件按作业隔离。

### FR-002 页面分类

页面类型：

- `native`
- `mixed`
- `scanned`
- `hidden_text_scan`
- `broken_encoding`
- `image_dominant`
- `unknown`

文档类型由页面分布聚合，禁止以单一文档标签覆盖所有页面。

### FR-003 原生提取

提取文字、字体、字号、粗斜体、颜色、坐标、图片、矢量对象和页面几何。正常原生文字为内容最高权威。

### FR-004 快速版面分析

PP-DocLayout_plus-L / PP-DocBlockLayout 用于简单页区域检测、复杂度判断和模型路由，不默认承担所有复杂页最终布局。

### FR-005 复杂版面分析

MonkeyOCRv2-B-Parsing 对复杂扫描、拍照、多栏、题图密集或快速布局低可信页面输出块类别、块级坐标、阅读顺序和初始内容候选。

### FR-006 文字 OCR

PP-OCRv6_medium_det/rec 为默认文字 OCR。输出文字框、内容和置信度。

### FR-007 表格

PP-StructureV3 为表格主引擎，输出行列、单元格、跨行跨列、单元格坐标和内容。低可信时保留表格区域图片。

### FR-008 公式

PP-FormulaNet 为公式主引擎；结果转 LaTeX/MathML/OMML，并回渲染验证。失败时保留公式图片。

### FR-009 Ovis 内容复核

只在高风险内容、表格/公式冲突、整页遗漏疑似或多模型冲突时调用 OvisOCR2。其结果作为候选和复核证据。

### FR-010 多模型融合

保留所有候选，不直接覆盖。区分：

- `engine_confidence`：模型原始置信度，可为空；
- `system_confidence`：由规则、一致性、几何和质量计算；
- `geometry_source`；
- `selected_candidate_id`；
- 选择理由和被淘汰候选。

### FR-011 文档结构

识别章节、大题、小题、题号、题干、子问题、选项、图片、图题、答题区、表格和公式关系。

### FR-012 题图归属

根据纵向边界、同栏、距离、阅读顺序、语义提示、题号范围和图题建立 `anchored_to`。低分不自动猜测。

### FR-013 DOCX

默认使用流式段落、原生表格、OMML、行内图片和无边框布局表格。复杂局部可整体图片降级。避免大量绝对定位对象。

### FR-014 QA

验证 Layout IR、内容完整性、阅读顺序、重复文字、题图关系、表格、公式、图片、DOCX 包完整性和可选回渲染。

### FR-015 审校

展示原页、区域、候选、来源和最终结果；支持改文字、元素类型、题图归属、渲染策略和区域重识别。人工修改必须记录审计。

### FR-016 作业管理

支持创建、进度、取消、失败重试、阶段产物、导出和清理。模型调用具有幂等键和超时。

### FR-017 模型网关

主应用只调用 `8100`。网关负责鉴权、限流、队列、模型路由、内部端口隔离、显存策略和统一返回格式。

## 6. 非功能需求摘要

- 稳定性：单页失败可隔离；支持安全降级。
- 隐私：默认离线/内网；不记录正文。
- 可维护性：模型可替换但 IR 不变。
- 可测试性：所有规则可使用固定输入测试。
- 性能：页面和区域按需渲染；重模型受控并发。
- 可观测性：记录耗时、模型版本、哈希、重试、降级和问题数，不记录正文。

## 7. 成功指标

- 纯电子文字不必要 OCR 调用率接近 0；
- 图片与所属题目关系准确；
- 无重复隐藏 OCR 层；
- DOCX 可打开率 100%；
- 低可信表格/公式错误强制输出率为 0；
- 所有最终块均具有来源、候选或明确的原生证据；
- 模型机不可用不影响纯电子基线。
