# 17. 验收标准

## 1. P0 必须满足

- 输入 PDF 不被修改；
- Layout IR 1.1 验证通过；
- 所有输出块有来源；
- DOCX 可打开；
- 模型失败有明确错误和降级；
- 普通日志不含正文；
- Agent Ticket 有测试和验证证据。

## 2. 纯电子 PDF

- 正常原生文字不调用 OCR；
- 标题、段落、图片和阅读顺序正确；
- 无模型机时仍完成；
- 主要文字完全可编辑；
- 无重复文字。

## 3. 混合 PDF

- 原生文字保留；
- 只对目标区域 OCR；
- 普通配图整体保留；
- 局部扫描文字可编辑；
- 题图关系不丢失。

## 4. 扫描 PDF

- 正文可编辑；
- 阅读顺序正确；
- 表格/公式按规则转换或降级；
- 图片不丢失；
- 复杂页有 Monkey 证据或明确降级。

## 5. MonkeyOCRv2

- 通过网关调用；
- 原始输出可追溯；
- 坐标转换正确；
- 未知标签不丢失；
- 无原始置信度时使用 null；
- 不直接覆盖 PP-OCR、表格或公式结果。

## 6. 题图

- 自动锚定有评分和证据；
- 低可信产生 Issue；
- Word 中图片不会漂移到其他题目；
- 图题与图不分离。

## 7. 发布门槛

- 黄金集回归通过；
- 阻断性 Issue 为 0；
- DOCX 可打开率 100%；
- 许可证/SBOM 完成；
- 模型版本和镜像 digest 固定；
- 安全检查通过。
