# 模型响应归一化

## 坐标

1. 读取输入图像实际宽高；
2. Monkey `[0,1000]` → 像素；
3. 区域像素 → 页面像素；
4. 页面像素 → PDF point；
5. 应用旋转/CropBox；
6. 校验边界。

## 标签

映射表配置化并版本化。未知标签保留 raw label 和 `unknown`。

## 内容

- 普通文本：保留原始和 NFC 版本；
- HTML：安全解析，移除脚本；
- LaTeX：只作为数据，不执行；
- Markdown：解析为候选，不作为 IR；
- OTSL：保存原始并转换为表格候选。

## 置信度

模型有概率则保存；无概率为 null。系统评分在 Fusion 层生成。
