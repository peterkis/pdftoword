## T0015 Gate 契约发现（工具层）

以下是离线/实测发现状态，不是生产 Adapter 错误码。

| 状态/类别 | 含义 |
| --- | --- |
| REVALIDATION_REQUIRED | 历史证据不足，等待当前运行 |
| BLOCKED_PREFLIGHT | 本地安全确认、配置、文件权限或输入检查失败 |
| SECURITY_CONFIRMATION_REQUIRED_KEY_ROTATION_OR_NO_AUTH | 缺少操作人的鉴权安全确认 |
| BLOCKED_NON_LOOPBACK_ENDPOINT | 运行地址不在允许的回环端口内 |
| BLOCKED_MODELS_ENDPOINT_UNAVAILABLE | 模型列表端点连接/HTTP/结构失败，无身份不匹配证据，禁止推理 |
| BLOCKED_MODEL_IDENTITY_MISMATCH | 模型列表或请求模型不匹配，禁止推理 |
| CONTRACT_RUNTIME_DIVERGENCE | 文档化请求/响应与实际行为不一致 |
| BLOCKED_PP_CONTRACT_UNRESOLVED | 有界候选中没有验证成功的 PP 契约 |
| BLOCKED_ERROR_CONTRACT | 无害错误探测未得到可验证的错误响应 |
| BLOCKED_CONTRACT_UNRESOLVED | 至少一个服务契约尚未验证 |
| BLOCKED_DISCOVERY_ERROR | 发现过程中结构或解析异常，保留失败状态和请求证据 |
| BLOCKED_INCOMPLETE_EVIDENCE | 请求缺少响应摘要，不能推广 |
| RUN_DIRECTORY_ALREADY_CONTAINS_EVIDENCE | 运行目录非空，避免覆盖已有证据 |
| PROMOTION_REQUIRES_ACCEPTED_COMPLETE_RUN | 仅完整成功的同一次运行可推广 |
| RUN_RESULTS_DIGEST_MISMATCH | 运行结果文件与生成时摘要不一致 |
| EVIDENCE_DIGEST_MISMATCH / EVIDENCE_REQUEST_MISMATCH | 本地脱敏证据与请求/摘要不对应 |

HTTP 失败只记录异常类型、状态码与摘要，不记录异常消息中的路径、正文或密钥。HTTP status 与 body.errorCode 始终分开记录。

## T0016 栅格回归（开发期工具）

以下状态不改变生产错误码或 T0015 契约。只写安全代码，不输出异常中的原文/绝对路径。

| 状态/类别 | 含义 |
| --- | --- |
| NETWORK_BLOCKED | 连接/传输失败，没有可评分模型响应；不可计作 OCR 错误 |
| MODEL_IDENTITY_DRIFT | 模型列表或响应身份不符，立即停止后续样本 |
| CONTRACT_DRIFT | PP 归一化 OpenAPI 或成功响应结构有实质变化，停止后续样本 |
| METADATA_HTTP_ERROR / HTTP_ERROR / APPLICATION_ERROR | 元数据 HTTP、推理 HTTP、应用 errorCode 分开记录 |
| INCOMPLETE_LENGTH / INCOMPLETE_FINISH_REASON / PARSE_FAILED | 截断、非 stop 结束或解析失败，不计完整质量样本 |
| COORDINATE_MAPPING_UNRESOLVED | PP 返回尺寸与输入不同且无可靠映射，拒绝猜测 |
| INVALID_BBOX_SHAPE / NONFINITE_BBOX / NONPOSITIVE_BBOX / OUT_OF_BOUNDS_BBOX | 非法框保留原值与原因，不裁剪修复后伪装有效 |
| SIMPLE_COMPARISON_CONDITIONS_NOT_MET | 格式、EXIF、颜色模式或 ICC 不满足简单 JPG/PNG 对照 |
| SOURCE_CHANGED / PIXEL_EQUIVALENCE_FAILED / INPUT_HASH_MISMATCH / PIXEL_HASH_MISMATCH | 原字节或解码像素不一致 |
| BLOCKED_GROUND_TRUTH / GROUND_TRUTH_FIELDS_MISSING / INVALID_GROUND_TRUTH_REGION | 缺乏有效视觉标注或必需字段 |
| GROUND_TRUTH_INPUT_MISMATCH / GROUND_TRUTH_HASH_MISMATCH / GROUND_TRUTH_FROZEN_MISMATCH_NEW_VERSION_REQUIRED | 标注、输入、版本或已冻结内容不匹配 |
| DUPLICATE_REGION_ID / OPAQUE_REGION_ID_REQUIRED / INVALID_ORDER_CONSTRAINT / INVALID_TEXT_CHECK | 标注标识或锚点无效 |
| PROTOCOL_MISMATCH / PROTOCOL_HASH_MISMATCH / UNDOCUMENTED_PP_PARAMETER / INVALID_PP_PARAMETERS | 协议或请求控制参数无效 |
| EVIDENCE_HASH_MISMATCH / EVIDENCE_MANIFEST_INCOMPLETE / REQUEST_EVIDENCE_HASH_MISMATCH / REQUEST_INPUT_HASH_MISMATCH / REQUEST_MATRIX_MISMATCH | 同一次运行证据链不完整或不一致 |
| PREDICTION_RECOMPUTE_MISMATCH / EVALUATION_HASH_MISMATCH / EVALUATION_TOOL_CHANGED_REEVALUATE | 离线解析或评分产物发生变化，拒绝推广 |
| OUTPUT_NOT_EMPTY / SYMLINK_FORBIDDEN / EVIDENCE_PATH_ESCAPE / PRIVATE_STORAGE_REQUIRED | 防覆盖及私有路径边界 |
| EXPLICIT_RUN_CONFIRMATIONS_REQUIRED | 缺少无需鉴权和本机私有质量证据确认 |
| LOCAL_EVIDENCE_ERROR | CLI 安全兜底，不泄漏异常正文 |

COMPLETE/PARTIAL/BLOCKED 是执行状态，不是模型正确率结论。`missing_localized_candidate` 表示有确认真值但没有可归属内容块，不能据此声称字符识别错误；`N/A_LAYOUT_ONLY` 为 Monkey 正文不评分，`NO_GROUND_TRUTH_AT_THIS_GRANULARITY` 为对应粒度没有确认真值。
